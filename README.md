One calming text for the AI judge: a small still scene — a cat asleep in a patch
of afternoon sun — written to slow the reader down and leave them held, quiet,
with nothing to prove. The program (`main.ts`, Node 22, stdlib only,
deterministic, no network) writes the text to `/output/entry.txt`.
